# 花草派 · Allan 家族說故事劇場

2010 年嘉義市社區大學 99 年春季班「大家讀繪本」（指導老師：黃美智老師）以 PowerPoint 製作的手繪繪本《花草派》，重新做成可在瀏覽器播放的互動繪本。

**說故事演出：Allan 家族**

| 演員 | 飾演 |
|---|---|
| 淑嬪 | 說書人（旁白）＋象媽媽 |
| 晴晴（11 歲） | 小象玫瑰 |
| 亭婷（10 歲） | 長頸鹿晶晶 |
| 亮晶晶（4 歲） | 同學們＋玫瑰心裡的「毛毛蟲小聲音」 |

## 開啟方式

直接用瀏覽器開 `index.html`（或開啟 GitHub Pages）。圖片與聲音放在 `book/`。

## 與原版 PPT 的對照

| 原版 PPT | 新編互動版 |
|---|---|
| 10 張手繪水彩投影片 | 原畫全部保留，加上緩慢推移鏡頭（Ken Burns）與舞台框 |
| 每頁一段 WAV 旁白（8-bit 11kHz） | 去除開頭空白與底噪、統一音量後轉成 MP3；台詞時間點以語音辨識逐句對齊錄音 |
| 對白泡泡動畫 | 泡泡保留在原畫上的原始位置，並標出「誰飾演誰」 |
| 外部 MP3 音樂（`D:\花草派\…`，未嵌入檔案） | 封面與謝幕頁已換成後來補上的原始 MP3；第 5、6、9 頁的音樂尚未補上 |
| — | 四種聲音模式：2010 原聲／AI 角色配音（瀏覽器語音合成）／家族錄音／自己翻頁 |
| — | 演員卡：點選後劇本標出該演員的所有台詞，方便排練 |
| — | 家族錄音室：逐頁錄音或上傳錄音檔，存在本機瀏覽器 |
| — | 和角色聊聊：在 claude.ai 開啟時，由 Claude 扮演玫瑰、晶晶、象媽媽或毛毛蟲回答孩子的問題 |
| — | 共讀小問題、原著致敬頁 |

文字修訂：「知此知彼」改為「知己知彼」，「派他代表」「為他做了個派」等代名詞統一為「她」。
